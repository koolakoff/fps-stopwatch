# Проверка версии 0.1.0

Дата: 28.10.2026.

## Окружение

- Windows, версия ядра/системы сборки 10.0.22631.
- Microsoft Visual Studio Build Tools 2026, MSVC 19.51, Windows SDK 10.0.26100.0.
- Release x64, статическая среда выполнения MSVC (`/MT`).
- Основной экран: 2560×1600, исходная частота 240 Гц; перечислены режимы 60 и 240 Гц.

## Выполнено

- Сборка без предупреждений компилятора.
- CTest: тесты часов пройдены; проверены начало с нуля, точность усечения до миллисекунд, длительный промежуток без кадров, пауза/продолжение, переход секунд/минут и расширение минут после 99.
- Полноэкранный DXGI/Direct2D запуск на реальном оборудовании.
- Автоматизированная проверка обработчиков Space, подавления автоповтора, паузы, продолжения, кнопки темы мышью, клавиши I и выхода Q.
- Снимки обеих тем из реального back buffer просмотрены: цифры не обрезаны, миллисекунды крупнее, отступ справа сохранён, строки содержат Hz, ms и пометки `(d)` / `(m)`.
- Временное переключение 240 → 60 Гц и возврат через D на 240 Гц успешно выполнены; разрешение проверяется при каждом применении режима. Отдельно проверены выбор 60 Гц через обработчик щелчка по строке и восстановление 240 Гц при завершении с активным режимом 60 Гц. Восстановленная частота повторно считана через Windows API.
- `dumpbin /dependents`: только системные `d3d11.dll`, `dxgi.dll`, `d2d1.dll`, `DWrite.dll`, `USER32.dll`, `ole32.dll`, `KERNEL32.dll`. Зависимости от Visual C++ Redistributable отсутствуют; WIC используется через системный COM.

## Границы проверки

- Приложение ещё не проверено на другом компьютере, чистой Windows 10, дробных частотах, повёрнутом экране, HDR и конфигурациях с несколькими мониторами.
- Интервал рассчитывается из частоты режима; фактическая частота появления новых кадров не измерена внешней камерой или PresentMon. Возможны пропуски кадров при нагрузке.
- Физическая точность FPV-измерения зависит от оборудования и не подтверждается тестами программы.
- При потере графического устройства приложение завершает работу с сообщением об ошибке и пытается восстановить режим; автоматическое пересоздание устройства пока не реализовано.
- Восстановление режима после принудительного завершения процесса или сбоя ОС не гарантируется.
- Reset: clock tests and graphics smoke test passed for keyboard reset while running and mouse reset while paused; running / paused state is preserved. Theme starts dark on each launch.
